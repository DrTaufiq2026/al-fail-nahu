# الفاعل · محاضرة النحو

عرض تقديمي تفاعلي لمحاضرة **الفاعل** في مادة النحو العربي.

- **المحاضر:** د. محمد توفيق
- **الكلية:** كلية الدراسات الإسلامية المعاصرة، جامعة السلطان زين العابدين
- **المرجع:** التطبيق النحوي، د. عبده الراجحي

## المحتوى
٢٣ شريحة: التعريف، العامل، الرفع وعلاماته، الفاعل المجرور لفظًا، التأخّر عن الفعل، وجوب ذكره ومواضع حذفه، إفراد الفعل، لغة «أكلوني البراغيث»، تأنيث الفعل، أنواع الفاعل، الرتبة مع المفعول، حذف الفعل، نموذج إعراب، خريطة ذهنية، تمرين تطبيقي، واختبار تفاعلي من ٢٠ سؤالًا مع تحليل النتائج في النهاية.

## الاستخدام
افتح `index.html` في المتصفح، أو فعّل GitHub Pages للمستودع.

| المفتاح | الوظيفة |
|---|---|
| ← / → أو المسافة | التنقل بين الشرائح |
| O | فهرس الشرائح |
| P | القلم (C للمسح) |
| S | البقعة الضوئية |
| F | ملء الشاشة |

على الشاشات اللمسية: اسحب يمينًا للشريحة التالية، ويسارًا للسابقة.

الرسوم التوضيحية مولَّدة بواسطة Gemini.
